# Краткий текст для курсовой

В рамках курсовой работы разработана учебная информационная система KOSTY, предназначенная для учета клиентов и обработки клиентских заявок. Система реализована на Python с использованием фреймворка Django, шаблонов Django, Bootstrap 5 и SQLite.

В проекте реализованы регистрация и авторизация пользователей, ролевая модель доступа, CRUD-разделы клиентов и заявок, журналирование событий безопасности, демонстрационная многофакторная аутентификация, учет доверенных устройств и GDPR-раздел. Ролевая модель включает администратора, менеджера, специалиста по безопасности, аудитора и обычного пользователя.

Принципы Zero Trust показаны через обязательную проверку каждого защищенного запроса, минимальные привилегии, фиксацию отказов доступа, журналирование событий и учет контекста устройства. GDPR представлен через хранение согласий на обработку персональных данных, экспорт данных пользователя в JSON, запрос на удаление данных, политику минимизации и сроки хранения.

Система является учебным прототипом и не претендует на production-ready реализацию. Демонстрационный MFA использует фиксированный код `123456`, что прямо указано в интерфейсе и документации.
