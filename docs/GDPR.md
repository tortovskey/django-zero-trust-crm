# GDPR в KOSTY

KOSTY демонстрирует базовые требования GDPR на учебном уровне.

## Согласие

В модели `Client` есть флаг согласия, дата согласия, статус согласия и цель обработки. Дополнительно `ConsentRecord` фиксирует историю согласий.

## Минимизация данных

Система хранит только данные, нужные для учебного сценария: профиль пользователя, контакты клиента, заявки, согласия и события безопасности.

## Право на доступ

Пользователь может скачать JSON со своими данными в разделе `GDPR -> Экспорт моих данных`.

## Право на удаление

Пользователь может создать `DataDeletionRequest`. Администратор рассматривает запрос и меняет статус.

## Ограничение срока хранения

Учебное правило:

- заявки хранятся 3 года;
- события безопасности хранятся 1 год;
- персональные данные клиента удаляются или обезличиваются после завершения цели обработки.

## Безопасность обработки

Используются Django authentication, password hashing, CSRF, RBAC и аудит событий. SQL-запросы выполняются через Django ORM.
